# Changelog

## v1.0.0 — 2026-09-18
- First public Windows packaging release.
- Targets Windows 10/11 x86-64 as a portable one-folder application.
- Packages PaedDeadSpace-Core v1.0.0 and PaedDeadSpace-UI v1.0.0.
- Local Streamlit launcher retains `global.developmentMode=false` and disables usage-statistics collection.
- Added deterministic build script, release metadata, checksum workflow, MIT license, and portable-package README.
