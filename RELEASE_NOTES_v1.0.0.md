# PaedDeadSpace-Windows v1.0.0

First public Windows portable distribution for PaedDeadSpace. The release asset packages Core v1.0.0 and UI v1.0.0 and is intended for offline/local use after extraction.

The binary is unsigned. Verify the published SHA-256 checksum. The release is complete only after the Pearsall golden benchmark is confirmed on the rebuilt v1.0.0 executable.
