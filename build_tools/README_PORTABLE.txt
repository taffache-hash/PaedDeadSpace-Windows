PaedDeadSpace: Pediatric Apparatus Dead-Space Explorer — Windows v1.0.0

Portable application for Windows 10/11 x86-64. Extract the complete ZIP and run PaedDeadSpace.exe. The adjacent _internal folder is required.

The application runs a local Streamlit server on 127.0.0.1 and opens it in your browser. No patient or user-entered model data are intentionally sent to an external server by PaedDeadSpace. Streamlit usage-statistics collection is disabled in the launcher. No OpenAI API key or Internet connection is required for runtime calculations.

For educational and research use only. Not intended for clinical decision-making or patient-specific treatment recommendations.

Included scientific components: PaedDeadSpace-Core v1.0.0 + PaedDeadSpace-UI v1.0.0.
